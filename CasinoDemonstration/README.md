# Весёлый слот — учебная слот-машина (RTP 90%)

Показывает детям, почему в «казиношках» выигрыши видны часто, а монетки всё равно уходят.

## Как запустить

Открыть `index.html` двойным щелчком — интернет и сервер не нужны
(без интернета будет только другой шрифт).

## Как проверить математику

- В браузере: открыть `tests/test.html`.
- Или в терминале (нужен Node.js):

```bash
node tests/payout.test.js
```

Тест перебирает все 100 комбинаций и проверяет: 40/30/15/10/4/1 комбинаций на выплаты
0/5/10/20/50/200, сумма выплат 900, RTP ровно 90%.

## Debug-режим

Открыть `index.html?debug` или нажать **Ctrl+Shift+D** во время игры.
Можно задать следующую комбинацию, проверить любой уровень выигрыша
и прогнать 1 000 / 10 000 / 100 000 вращений без анимации.

## Файлы

| Файл | Что внутри |
|---|---|
| `js/logic.js` | Барабаны, таблица выплат, статистика — вся математика |
| `js/symbols-config.js` | Названия, эмодзи, цвета и картинки символов |
| `js/app.js` | Интерфейс, анимации, эффекты, итоговый экран |
| `js/sound.js` | Звуки (синтезируются в браузере, файлы не нужны) |
| `css/style.css` | Оформление |

## Как поставить свои картинки

В `js/symbols-config.js` впишите путь к картинке в поле `image`, например:

```js
PAW: { name: "Щенята", emoji: "🐶", color: "#3b82f6", image: "images/paw.png" },
```
